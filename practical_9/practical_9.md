## Introduction

Prim's algorithm finds a minimum spanning tree (MST) for a connected, weighted, undirected graph. It starts from one vertex and repeatedly adds the lowest-weight edge that connects the current tree to a vertex not yet included. This practical uses an adjacency matrix to represent the graph.

## Conclusion

Prim's algorithm constructs a minimum spanning tree by growing one connected tree and choosing the least costly available edge at each step. The resulting tree connects all vertices without cycles and has the minimum possible total edge weight.
