## About the Subject

Design and Analysis of Algorithms (DAA) focuses on developing efficient solutions to computational problems. It covers algorithm design techniques, analyzing time and space complexity, and comparing the performance of different approaches.

In this lab, practical implementations demonstrate concepts such as sorting and searching, graph traversal, dynamic programming, and minimum spanning tree algorithms. These exercises help build problem-solving skills and show how algorithmic ideas can be applied in code.
