# Practical 3: Max Heap Sort

## Summary
Heap sort is a sorting technique that uses a max heap to arrange elements in sorted order. It repeatedly places the largest element at the root and then swaps it with the last element, rebuilding the heap until the array is fully sorted. This method is efficient and works in-place.

## Conclusion
In this practical, we learned that heap sort is an efficient sorting algorithm with O(n log n) time complexity. It is useful for sorting large data sets and helps us understand how binary heaps can be used in data structure applications.
