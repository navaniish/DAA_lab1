## Introduction

Breadth First Search (BFS) and Depth First Search (DFS) are graph traversal algorithms used to visit vertices and explore connections. BFS visits vertices level by level using a queue, while recursive DFS follows one path as far as possible before backtracking. This practical demonstrates both algorithms on a graph represented by an adjacency list.

## Conclusion

BFS and DFS provide two useful ways to traverse a graph. BFS explores nearby vertices first, while DFS explores paths deeply before returning. Both algorithms visit reachable vertices in time proportional to the number of vertices and edges.
